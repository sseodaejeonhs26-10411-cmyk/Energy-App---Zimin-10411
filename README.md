# 에너지체크

이동 수업 시간표, 불·히터 체크, 확인 기록을 한 페이지에서 사용하는 에너지 절약 앱입니다.

## 실행

이 폴더에서 `python -m http.server 8000`을 실행하고 http://localhost:8000 에 접속하세요.

## Vercel 배포

이 저장소를 연결하고 Framework Preset을 Other, Root Directory를 저장소 루트로 지정하세요. 빌드 명령과 설치 명령은 필요 없습니다. 정적 파일을 그대로 배포합니다.

## 기능과 범위

- 매주 반복하는 이동 수업 시간표 등록·삭제
- 불·히터 상태를 각각 확인하고 이름과 시각 저장
- 최근 확인 기록, 이전 기록 펼쳐보기, CSV 저장
- 앱을 열어둔 기기에서 수업 시작 5분 전 알림

데이터는 이 브라우저에 저장됩니다. 학급 전체 푸시와 기기 간 공유는 지원하지 않습니다.
